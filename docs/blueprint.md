# **App Name**: Lensbox Feedback Hub

## Core Features:

- Data Entry Form: Form fields for S.No., Date of Delivery, Customer Name, Phone Number, Call Done By, and Salesman Comments to capture lens feedback call data.
- Admin Authentication: Secure authentication for admin users (preethikaeyecare@gmail.com and eyecarepreethika@gmail.com) with privileged access for viewing and approving data.
- Role-Based Access: Controls based on who is using app.
- Data Visualization: Interactive dashboards with graphs and charts to display updated sales statistics and trends.
- Customizable Follow-up Messages: Admin interface for setting up a company logo and default follow-up WhatsApp message templates.
- Contact Management: A log where admins add employees name, numbers
- AI-Powered Sentiment Analysis: Utilize an AI tool to analyze salesman comments and suggest key trends or opportunities in customer feedback.

## Style Guidelines:

- Background color: Off-white (#FAFAFA) to ensure clarity and reduce eye strain during extended use.
- Primary color: Deep blue (#3F51B5) for headers and actionable items, projecting professionalism.
- Accent color: Cyan (#00BCD4) to draw user attention.
- Body font: 'PT Sans', a clear, modern font for form fields and data displays. Headline font: 'Space Grotesk', geometric with a contemporary appearance, well-suited to information-driven contexts.
- Note: currently only Google Fonts are supported.
- Use clean, consistent icons to represent actions and data categories; avoid decoration in favor of clarity.
- Clear sectioning and separation to display each type of information
- Subtle transitions, such as fade-ins, to add refinement
